# 상품 목록 페이지 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 모바일 신발 쇼핑몰 상품 목록 페이지

### 사용하게 될 기술: React Native,React

### 문서 작성자: 볶음밥

## 📝 고객 요구사항 정리

모바일 화면에서도 가독성 좋은 쇼핑몰 화면
상품명보다 상품 사진 비율이 큰 배치의 디자인
장바구니에 담긴 품목 개수를 확인하기 쉽게
직원들이 확인할 URL


## 📋 기능 목록
- 상품 리스트
- 상품을 2개의 컬럼으로 보여준다.
  - `<ProductList />`
  - 상품 이미지가 담겨있는 컬럼
 -장바구니 리스트
 -장바구니에 담긴 상품을 2개의 컬럼으로 보여줌
-장바구니에 담겨있는 상품은 '담김'으로 표시되고, 버튼 색도 바뀜
-장바구니 품목 개수가 바뀌면 화면 상단 장바구니 아이콘에 있는 숫자 업데이트
