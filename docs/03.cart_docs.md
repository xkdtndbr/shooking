# 장바구니 프로젝트

## 프로젝트 개요

- 프로젝트 목표와 주요 기능에 대한 간략한 설명 : 스토리북을 이용한 장바구니 페이지 제작
- 참여한 팀원 : 볶음밥

## 개발 환경

사용한 프레임워크, 라이브러리, 언어 등
React 17.0, JavaScript ES6

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어

```
npm install
npm start
```

## 컴포넌트 구조

주요 컴포넌트들의 구조와 역할 : 장바구니에 담긴 상품의 금액 확인, 배송비, 뒤로가기 버튼, 결제하기 버튼, 카드 등록 및 결제

## 테스트 방법

테스트 케이스 및 실행 방법

```
npm test
```
